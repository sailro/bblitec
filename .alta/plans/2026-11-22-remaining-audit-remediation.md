# Remaining audit remediation

**First deliverable:** a bloom scale of `0.3` produces a 30×30 target at 100×100, and a compute shader may name an ordinary buffer `bbl_num_workgroups` without SDL replacing its contents. Both fixes can be built and tested in this Windows checkout. Neither should wait for minimum-package dependencies or an Android device.

Work from the **current working tree**, including `native/shader-deployment.cmake`, not a clean `HEAD`. Preserve unrelated edits, untracked references, source/Tint pins, corpus, goldens and thresholds. Use separate ignored output directories. Each step is independently verifiable; an unavailable device or stale dependency leaves its gate open in `audit.md`, not marked passed.

## What changes first

**Bloom — keep the sizing rule, not its sampled result.** `src/pinned-post-process.ts` currently divides an integer target extent by a probe extent. Once rounded, that number cannot recover the authored scale. Keep executing the factory for pass wiring and format. Trace the reached `createScaledBloomTarget` and `resizeScaledBloomTarget` expressions in the pinned `post-process/bloom.ts`; lower their descriptor-size expressions with the shared body/expression lowerer. Bind the actual factory scale (including its default) and the current resolved source dimensions. Use the resulting sizing policy at creation and re-record through `src/lowering/post-process-lowerer.ts` and the shared target resolver. PAL allocates the returned extent; it does not implement bloom arithmetic. Leave the separate screen-space rounding policy intact. Refuse a sizing expression the compiler cannot represent rather than infer another ratio.

```text
source 100×100, bloomScale 0.3 → extract 30×30, blur-X 30×30, blur-Y 30×30
resize to 101×99              → extract 30×29, blur-X 30×29, blur-Y 30×29
```

**Compute — distinguish a binding's role from its WGSL spelling.** Have `sdlWorkgroupCountsSource` return the adapted WGSL **and** the allocated group/binding. Choose a private identifier unused in the module and affected function scopes; a different fixed prefix is not a fix. `src/compile-shaders.ts` already sees Tint's reflected slots per entry point before it caches `.slots`. Match the recorded pair to that entry's reflected read-only storage slot and annotate its role there. No new Tint build should be needed. Preserve the original Dawn layout and WGSL. In `pal_sdl_gpu_compute_pipeline.hpp`, bind dispatch counts only for that role; a variable name is diagnostic text.

```text
Authored buffer named bbl_num_workgroups → bind the application's buffer
Injected slot for @builtin(num_workgroups) → bind this dispatch's (x, y, z)
```
