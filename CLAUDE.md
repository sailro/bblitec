# bblitec

The repository instructions live in
[`.github/copilot-instructions.md`](.github/copilot-instructions.md).
Read that file first; it is the single copy, and this page exists only so
that agents looking for `CLAUDE.md` find it.

The one habit it opens with, repeated here because it is the one most
often skipped: **a rendering difference is answered by a capture, not by
reasoning about the picture.** Start with `npm run scene -- diff <id>`
and the ladder in [`docs/debugging.md`](docs/debugging.md).
