Scope: the [pinned Babylon Lite package](upstream/babylon-lite.json), its compiler and the Windows desktop build. ## Assessment

| Question | Finding | Evidence / limit |
| --- | --- | --- |
| API or asset activation? | Both. A reached call can install a feature; `loadGltfFeatures` also imports features selected by an extension name or a document predicate. A skin needs joints on a primitive; animation alone does not imply a skin. | [Asset specialization](src/asset-specializer.ts) reads the packaged loader result; [the join](src/asset-feature-join.ts) projects it with API reach. This is not a reason to add per-scene switches. |
| Are engine operations transpiled? | Not all. The point renderer uses pinned shader text and lowers task selection and draw deferral. Device pass instrumentation remains adapted under a source contract. | [Pass contracts](src/lowering/gps-pass-contract.ts), [library adapters](src/lowering/splat-stream-library.ts); `trogir-streaming` reaches this path. |
| Is every TypeScript construct implemented once? | Shared syntax, type, operator and evaluation-order owners serve more than one lowering path. Entry code, closed execution and pinned bodies admit different inputs; one visitor for all three is not established. | [Compiler invariants](docs/architecture.md#lowering-invariants). An unused export is not an unused implementation; fixture asset generators also have manual entry points. |
| Are the renderers independent? | `scene1`'s existing SDL_GPU-only and Dawn-only compile databases each contain 25 commands, including the PCH and only the selected renderer unit; the dual build contains 26. | [CMake selector](native/backend-sources.cmake), [missing-renderer selection fixture](test/backend-tu-sync.test.ts). This checks build membership, not every scene/platform after deleting a renderer. |
| How much PAL should be shared? | Share frame order, synchronization and layout; leave command encoding and in-flight resource ownership with the device API. | [Backend owners](docs/backends.md#code-layout). Comparing final pixels alone cannot detect a shared defect. |
| Are the patches tracked? | Inventory checks 109 ordered patches across seven libraries, including 69 for RmlUi. File membership and build-series identity are separate from applicability and runtime qualification. | [Manifest](native/patches/manifest.json), [identity reader](native/patch-identity.cmake), [setup](docs/development.md#setup). The manifest distinguishes 97 unsubmitted, eight vcpkg, three closed and one merged patch; those labels do not establish that a patch can be removed at this pin. |
| Does generated C++ have lifetime evidence? | Mesh, transform-node and object-URL slots stop recycling at their maximum generation. Five Windows allocator/GC fixtures pass under ASan, including the WeakMap allocation-failure path. A bounded working-set trend or successful ASan run is not a leak check of the whole process. | [Reclamation fixtures](test/record-reclamation.test.ts), [memory checks](docs/debugging.md#memory). |
| Is a new diagnostic CLI needed? | No new command is required for these findings. `diagnose` calls the existing parity, diff and composition paths. Single-backend diagnostics use the compiled renderer when neither a flag nor the runtime environment chooses one. | [Diagnosis ladder](docs/debugging.md#the-ladder), [dispatch tests](test/scene-command-dispatch.test.ts). |
| Do minimum builds compile and bundle only necessary files? | Backend source selection and final shader deployment filter the unselected renderer, but development dependencies are deliberately a superset. The shader deploy target now uses the backend-selected file list directly; no intermediate snapshot is needed. Current minimum packages are not qualified. | [Shader deployment](native/shader-deployment.cmake), [build fixture](test/build-options.test.ts). [Shipping](docs/development.md#minimal-size-shipping-builds). |

## Remediation

- [x] Point-pass task selection and draw deferral lower their pinned predicates. Installation/release, native pass discovery, draw tracking and pause/resume remain device seams. `trogir-streaming` and `trogir-points` pass both backends.
- [x] Bloom allocation and resize use [the lowered extent](src/lowering/render-target-size.ts) and the factory's exact scale. `ocean` passes both renderers and all `ocean-resolution` expectations.
- [x] SDL dispatch counts have a versioned sidecar role selected by reflected binding identity. Authored buffer names remain ordinary resources; [GPU fixtures](test/webgpu-subset.test.ts) distinguish both values.
- [x] Non-Unicode and Unicode RegExp replacements use the JS capture substitution rules. [Node/native fixture](test/regexp-unmatched-groups.test.ts).
- [x] UV/emissive composition consumes the selected pointer parser's recorded per-material state. [Physical-slot and pin-mutation fixtures](test/gltf-animation-pointers.test.ts); `scene242` and `scene253` pass both renderers.
- [x] Read `.babylon` light activation and mesh lists from lights the pin actually creates. Report eight-influence truncation from constructed skeleton buffers; omit the diagnostic-only diffuse UV2 switch. [Loader fixtures](test/asset-specializer.test.ts).
- [x] Preserve double intensity at the `.babylon` point-light factory boundary. The [loader fixture](test/babylon-hierarchy.test.ts) compares the loaded and direct records at intensity 16777217.
- [x] [The LUT bake](src/ibl-brdf-lut.ts) executes `generateBrdfLut` with readback usage added; [IBL recording](src/gltf-ibl-plan.ts) records the result without restating dispatch counts. `scene265` and `scene342` pass both renderers.
- [x] Search live skinned instances in packaged scene traversal order. [Native fixture](test/asset-root-find.test.ts) covers reversed, empty and partial roots. `scene218` and `scene219` pass both Windows renderer parity gates.
- [x] Resolve the whole module-relative URL before applying pathname replacements. [Compiler fixture](test/compiler.test.ts) covers encoding, parent segments, cross-boundary replacements, side effects and invalid URLs.
- [x] Resolve numeric builtins by declaration, defaulted generic arguments by instantiated signature and forwarded Recast arguments by AST. Wrapped and shadowed globals, a default-only parameter and reordered arguments have focused tests.
- [x] Validate shipping executable stamps per slice, reject stale deployments when the last generated asset disappears, and record the smoke frame limit rather than claiming observed frames. [Package fixtures](test/shipping-demos.test.ts).
- [x] Compatible shipping trees retain objects and payloads; stale or unrecognized trees refuse reuse. [Shipping fixtures](test/shipping-demos.test.ts) check identical inputs, one TU edit and configuration/patch mismatches. Windows Dawn development baseline (four Ninja jobs, private ccache, preinstalled dependencies; configure excluded): `scene218` cold 32.439 s, unchanged 0.126 s, one native TU edit 0.574 s; adding `scene219` 25.917 s. One sample per condition, not a shipping or optimality claim.
- [ ] Build fresh Windows minimum packages for `scene1`, `tetris`, `minecraft`, `doom` and `trogir-streaming`; verify thin-slice identity, link maps, deployed membership, notices, startup and archive bytes. Saved receipts are not measurements of this checkout.
- [ ] Qualify the Android surface-loss patch on an actual surface replacement after resume. A Windows `scene164` device-loss result does not exercise that path.
- [x] `minecraft`, `doom`, `offscreen`, `scene164` and `trogir-streaming` pass bounded Windows working-set checks on SDL_GPU and Dawn. Matching build stamps and complete per-engine samples: `artifacts/remaining-audit/engine-profile/memory/`. Whole-process leak qualification remains [open](TODO.md#qualification).
- [ ] Qualify interaction sequences outside the [declared checks](docs/debugging.md#checks); parity at a single pose is insufficient.
